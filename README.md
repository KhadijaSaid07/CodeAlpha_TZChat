# TZChat – Connect. Chat. Share.

TZChat is a full-stack social networking and messaging platform built for the CodeAlpha Full Stack Development Internship (Task 2).

## Features
- Secure JWT authentication with HttpOnly refresh cookies
- User profiles with Pillow-validated avatars and cover images
- Separate Followers and Mutual Friends systems
- Posts (text, images, videos with captions), comments, and likes
- Real-time 1-to-1 and Group messaging via Django Channels (WebSockets)
- Message requests, notifications, granular privacy settings, and user blocking
- Reporting, moderation with PDF export, RBAC Admin Dashboard API, and immutable Audit Logs
- OpenAPI / Swagger UI documentation via `drf-spectacular`

## Technology Stack
- **Backend:** Python, Django, Django REST Framework, PostgreSQL, Django Channels, Simple JWT, `drf-spectacular`, Pillow
- **Frontend:** React, Vite, JavaScript, HTML5, CSS3
